# Library Management System Backend

This is the backend for a complete Library Management System built with the MERN stack.

## Features

- User authentication with JWT
- Book management (CRUD operations)
- Transaction management (borrowing, returning, purchasing)
- Community features (genre, author, and interest-based spaces)
- Post and comment functionality
- Notification system
- Admin panel
- Real-time inventory tracking

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- MongoDB (local or Atlas)
