# Library Management System Frontend

This is the frontend for a complete Library Management System built with React.

## Features

- User authentication with JWT
- Book browsing and searching
- Book borrowing and purchasing
- User profile management
- Community features
- Notifications system
- Admin panel for managing books, users, transactions, and communities

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
